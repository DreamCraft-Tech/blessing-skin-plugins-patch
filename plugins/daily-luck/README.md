# 今日人品与千万别点 1.2.2

在 Blessing Skin 用户仪表板首页插入“今日人品与千万别点”组合卡片。每位用户每天获得 0–100 分的结果，以及一句 Minecraft 风格短评；0 分和 100 分有独立彩蛋文案。

## 安装与配置

适用当前 Blessing Skin 6.x PHP 8.5 分支及 Laravel 10。

1. 上传 `daily-luck_1.2.2_php85.zip` 并启用，或将包内 `daily-luck/` 解压至网站 `plugins/`。
2. 登录用户仪表板，卡片默认位于右栏公告下方，点击“查看今日人品”展示结果。当天查看后按钮禁用并显示“明天再来看看？”，结果持续展开，刷新或更换设备后保留。次日首次访问恢复可点击状态。
3. 在“插件配置 → 今日人品与千万别点”独立开启或关闭两个功能，调整卡片标题、左栏或右栏位置，以及人品结果的“点击查看 / 直接展示”。管理员可查看配置，超级管理员可保存。
4. 更新文件后，按站点 OPcache 配置刷新 PHP 运行环境。

日期采用站点 `app.timezone`，每日 00:00 切换；跨日后重新打开或刷新仪表板展示新日期。相同账号在同一天刷新、退出重登或更换设备，结果一致。展示文案以 Minecraft 冒险、建筑、种田等活动为主题。

## 自定义短评与互动彩蛋

“今日人品短评”中一行填写一条文本，最多 100 条，每条最多 200 字。空行和行首尾空格在保存时整理。每位用户每天固定选取其中一条，分数计算保持原规则；留空使用默认的分数分段短评。文本按纯文本显示，保存后的文案用于后续页面请求。

“千万别点”前两次点击展示趣味提示，第三次触发仪表板配色。可选择缤纷配色、奶油纸张、卡片乱飞、页面抖动、忽大忽小、大闹仪表板、躲避鼠标或随机彩蛋。动态效果支持轻柔、活泼与邪性强度。效果持续 15、30 或 60 秒，点击固定在页面右下角的“恢复原样”、卡片内的恢复按钮、按 Esc 或离开页面时清理效果。动画遵循浏览器的减少动态效果偏好，此时动态彩蛋改为静态配色。卡片移动使用 CSS transform，恢复时移除插件添加的动画类。互动状态仅保存在当前页面。

两项都关闭时，仪表板隐藏组合卡片。今日人品关闭时，查看接口也随之关闭。重新开启后继续使用已保存的当天查看状态。

从每日人品 1.0.x 升级时覆盖原 `daily-luck/` 目录并重新启用，插件管理显示名称更新为“今日人品与千万别点”。插件标识、配置键、用户查看日期表和原分数算法保持一致，已有自定义标题沿用。

## 技术实现

通过 `grid:user.index` 添加 Twig 卡片，沿用 AdminLTE / Bootstrap 的卡片、按钮和表单组件。结果由站点 APP_KEY、用户 UID、站点日期进行 HMAC-SHA256 运算，映射至 0–100。修改 APP_KEY 会改变结果序列。页面以服务端日期生成，客户端时钟不参与计算。

插件配置写入主站 options；使用 `daily_luck_users` 表按 UID 保存最近一次查看日期；启用或启动插件时初始化表。无前端构建步骤或 Composer 依赖。用户仪表板响应设置为 `Cache-Control: no-store, private`。所有分数和短评均由本插件算法生成。

## 验证

源码包包含 PHPUnit 测试，使用主站开发依赖运行：

```sh
BLESSING_SERVER_PATH=/absolute/path/to/blessing-skin-server php /absolute/path/to/blessing-skin-server/vendor/bin/phpunit -c /absolute/path/to/daily-luck/phpunit.xml
```

覆盖同日稳定性、分值范围、多用户分布、站点时区跨日、彩蛋文案、仪表板集成、已有组件保留、位置与展示设置、权限、标题转义和 CSRF。新增独立功能开关、旧版配置兼容、自定义短评的整理与转义、效果参数校验；JavaScript 测试覆盖连续点击、计时器、恢复与减少动态效果偏好。
